App Predicción Precio Vivienda

Machine Learning end-to-end con Python y Flask

Este proyecto consiste en el desarrollo de una solución completa de Machine Learning aplicada a la predicción del precio de viviendas. A partir de un conjunto de datos inmobiliarios, se realizó un análisis exploratorio de los datos para comprender la distribución de las variables, detectar valores atípicos y analizar la relación entre las características de las viviendas y su precio de venta.

Posteriormente, se implementó un proceso de preprocesado de los datos mediante pipelines, incluyendo la imputación de valores faltantes y la codificación One-Hot de variables categóricas. Se entrenaron y compararon distintos modelos de regresión, seleccionando finalmente un modelo Random Forest por su mejor rendimiento y capacidad de generalización.

🔧 Tecnologías
Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · Flask · Joblib · HTML · CSS · Bootstrap · SQLite

El modelo final se integró en una aplicación web desarrollada con Flask, que permite a los usuarios introducir las características de una vivienda y obtener una estimación del precio en tiempo real. El proyecto cubre todo el ciclo de vida de un sistema de Machine Learning, desde el análisis inicial de los datos hasta su puesta en producción.
