LUCA HOME

Gestor de tareas del hogar con gamificación · PWA · segunda versión mejorada del Trabajo Fin de Ciclo (TFC)

LUCA HOME es un proyecto personal que nace como una segunda versión mejorada de mi Trabajo Fin de Ciclo (TFC). Partiendo de la idea original, decidí rehacerlo desde cero con una arquitectura más sólida, una experiencia de usuario más cuidada y muchas funcionalidades nuevas, aplicando todo lo aprendido desde entonces.

Es una PWA (Progressive Web App) para organizar la vida doméstica en familia o entre compañeros de piso. Convierte las tareas del hogar en un juego: puntos, niveles, insignias, retos diarios y recompensas canjeables, todo dentro de "hogares" compartidos entre varios miembros.

Funcionalidades destacadas

  • Tareas y gamificación: asignación con puntos, niveles e insignias, ordenación inteligente (vencidas primero) y sistema anti-trampas con validación entre miembros.
  • Retos y recompensas: retos diarios aleatorios y catálogo de recompensas canjeables con puntos.
  • Cuentas del hogar (estilo Tricount): gastos compartidos con varios modos de reparto y algoritmo de transferencias mínimas para saldar deudas con el menor número de pagos.
  • Multi-hogar y roles: un usuario puede pertenecer a varios hogares con invitaciones por código y permisos por rol (admin / miembro).
  • Y más: ranking semanal/mensual, presupuestos, documentos, listas de la compra, calendario, mascota virtual que evoluciona, modo oscuro y diseño mobile-first.
Arquitectura y decisiones técnicas

PWA instalable con service worker propio (precache con Workbox) · Backend serverless sobre Supabase con Row Level Security · Lógica sensible en funciones SECURITY DEFINER de PostgreSQL · Notificaciones push event-driven (Database Webhook → Edge Function que firma el push con VAPID) · Tareas programadas con pg_cron · Almacenamiento privado con URLs firmadas temporales
🔧 Tecnologías React 19 · Vite · Tailwind CSS v4 · React Router 7 · React Hook Form · Supabase (PostgreSQL + Row Level Security + Edge Functions) · vite-plugin-pwa · Workbox · Web Push API + VAPID · lucide-react · date-fns · Vercel

A diferencia de la versión original del TFC, en LUCA HOME he priorizado la calidad y la profundidad técnica: una PWA real con notificaciones push nativas, seguridad a nivel de base de datos con RLS, lógica de negocio bien encapsulada y una experiencia de usuario mobile-first. El resultado es una aplicación desplegada y funcional que refleja mi evolución como desarrolladora y mi forma de afrontar un proyecto de principio a fin.
