Proyecto destacado

UniSocial

Red social y plataforma de productividad colaborativa · proyecto full-stack en producción

UniSocial une la organización personal con lo social: gestión de tareas, proyectos y calendario junto a chat en tiempo real, grupos, amigos y un feed. Todo en una sola plataforma, pensada para estudiantes y equipos que quieren organizarse sin complejidad.

Es un proyecto full-stack real, desplegado en producción, con una arquitectura de tres aplicaciones: una API REST con WebSockets, la aplicación principal y una landing de presentación.

🔧 Tecnologías
Next.js · React · TypeScript · Tailwind CSS · Node.js · Express · Prisma · PostgreSQL · Socket.IO · NextAuth (JWT) · PWA · Docker

Priorización inteligente. Cada tarea recibe automáticamente una puntuación que combina varios factores —palabras clave críticas, cercanía de la fecha límite, duración, estado e importancia— para ordenar de forma automática lo que conviene hacer primero. El estudiante ve, sin esfuerzo, qué es lo urgente.

Tiempo real bien resuelto. El chat y la presencia "online" funcionan por WebSockets. La presencia se deriva de la última actividad mediante un heartbeat ligero, evitando escrituras constantes en base de datos y reduciendo la carga del sistema.

Seguridad y permisos. Sesión unificada con JWT entre la API REST y los WebSockets, contraseñas cifradas, rate limiting en los endpoints sensibles y un sistema granular de roles (propietario, administrador, miembro) en grupos y proyectos.

UniSocial ha sido mi proyecto más completo: arquitectura de varias apps, tiempo real, seguridad, modelado de datos y experiencia de usuario cuidada de principio a fin.
