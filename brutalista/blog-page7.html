Proyecto en equipo

UniSocial

Red social y plataforma de productividad colaborativa · proyecto full-stack en producción · desarrollado con el equipo de Axioma Creativa

UniSocial une la organización personal con lo social: gestión de tareas, proyectos y calendario junto a chat en tiempo real, grupos, amigos y un feed. Todo en una sola plataforma, pensada para estudiantes y equipos que quieren organizarse sin complejidad.

Es un proyecto full-stack real, desplegado en producción y desarrollado en equipo junto a Axioma Creativa, con una arquitectura de tres aplicaciones: una API REST con WebSockets, la aplicación principal y una landing de presentación.

Lo que lo hace especial Priorización inteligente de tareas con un algoritmo de scoring · Tiempo real con WebSockets (chat y presencia online) · Autenticación JWT compartida entre API y WebSockets · Sistema de roles y permisos en grupos y proyectos · Notificaciones push (PWA instalable) · Colaboración con subtareas, comentarios y adjuntos
🔧 Tecnologías Next.js · React · TypeScript · Tailwind CSS · Node.js · Express · Prisma · PostgreSQL · Socket.IO · NextAuth (JWT) · PWA · Docker

Priorización inteligente. Cada tarea recibe automáticamente una puntuación que combina varios factores —palabras clave críticas, cercanía de la fecha límite, duración, estado e importancia— para ordenar de forma automática lo que conviene hacer primero. El estudiante ve, sin esfuerzo, qué es lo urgente.

Tiempo real bien resuelto. El chat y la presencia "online" funcionan por WebSockets. La presencia se deriva de la última actividad mediante un heartbeat ligero, evitando escrituras constantes en base de datos y reduciendo la carga del sistema.

Seguridad y permisos. Sesión unificada con JWT entre la API REST y los WebSockets, contraseñas cifradas, rate limiting en los endpoints sensibles y un sistema granular de roles (propietario, administrador, miembro) en grupos y proyectos.

UniSocial ha sido un proyecto de equipo muy completo: arquitectura de varias apps, tiempo real, seguridad, modelado de datos y experiencia de usuario cuidada de principio a fin. Trabajar con el equipo de Axioma Creativa me ha permitido participar en un desarrollo real, coordinado y orientado a producción.
